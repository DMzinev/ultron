## 4. Known Limitations

Before deploying or integrating `v1.5.0rc1`, please note the following technical and architectural boundaries:

1. **Python-Only AST Metric Depth**: The core static analyzer calculates full Abstract Syntax Tree (AST) metrics (McCabe cyclomatic complexity, coupling fanout, inheritance depth) specifically for Python source files.
2. **Syntactic & Topological Scope**: Ultron performs static syntactic and topological graph analysis. It does not execute untrusted code dynamically or perform dynamic runtime taint tracking.
3. **Git History Dependency**: Historical churn metrics and co-change coupling analysis require a valid Git repository with cloned history (`fetch-depth: 0` in CI). Shallow clones produce default fallback baseline churn scores.
4. **Coverage Ingestion Requirement**: Test coverage scoring requires an existing, pre-generated Cobertura XML (`coverage.xml`) or SQLite `.coverage` file generated by test runners.
5. **Production PyPI Gate**: Production PyPI upload is locked during the RC candidate stabilization phase; pre-release packages are distributed via TestPyPI and GitHub Releases.

## 5. Exact Skip & Environment Policy Notes

Ultron adheres to an uncompromising, verifiable skip policy:

- **Standard CI and Local Development**: **Zero test skips are permitted**. The verification suite runs 1,026+ automated tests with 0 failures, 0 errors, and 0 skips (`TESTS: 1026 ran, 0 failed, 0 errors, 0 skipped`).
- **Bounded Skips**: Bounded skips (up to 9 tests maximum) are permitted **only** when optional external network fixtures (such as live HTTP endpoints) or optional dev fixtures are physically absent from the host environment.
- Any unauthorized `unittest.skip` or unmarked omission will immediately fail the repository gate (`scripts/verify.py`).

## 9. Model Context Protocol (MCP) Configuration Repair and Uninstall

Ultron provides native multi-client IDE configuration management for Model Context Protocol (MCP) servers across Cursor, Claude Desktop, Windsurf, and VS Code.

### Uninstalling MCP Configuration
To cleanly remove Ultron from your IDE's MCP configuration without modifying other configured servers:
```bash
# Target specific client
ultron mcp uninstall --client cursor
ultron mcp uninstall --client claude
ultron mcp uninstall --client windsurf
ultron mcp uninstall --client vscode

# Target all supported clients simultaneously
ultron mcp uninstall --client all

# Target global user configuration instead of repository local
ultron mcp uninstall --client cursor --global

# Alternative flag syntax
ultron mcp --uninstall --client cursor
```

### Repairing and Re-verifying MCP Configuration
If an IDE config file becomes corrupted or points to an outdated Python interpreter:
```bash
# Repair specific client
ultron mcp repair --client cursor

# Repair all clients
ultron mcp repair --client all

# Repair global user configuration
ultron mcp repair --client cursor --global

# Alternative flag syntax
ultron mcp --repair --client cursor
```

The repair command validates JSON syntax, creates a timestamped backup if corrupted (`.bak.<timestamp>`), updates the `sys.executable` path, and restores the canonical `ultron` server entry atomically.
